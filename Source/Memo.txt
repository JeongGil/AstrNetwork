언리얼 네트워크에서의 주요 클래스
GameMode : 서버
DefaultPawn : 서버, 클라
PlayerController : 서버, 클라

RPC : 네트워크에서 다른 컴퓨터에게 함수 실행을 요청하는 기능.
UFUNCTION 옵션으로 지정이 가능하다.
Server : 클라이언트가 서버에 요청할 때 사용.
Client : 서버가 특정 클라이언트에게만 함수를 호출하고 싶을 때 사용.
NetMulticast : 서버가 모든 클라이언트에게 함수를 호출하고 싶을 때 사용.

Reliable : 반드시 실행이 보장되어야 하는 요청에 사용.
Unreliable : 안붙이면 기본 옵션이다. 자주 호출되고 한두번 놓쳐도 괜찮을 때 사용.
